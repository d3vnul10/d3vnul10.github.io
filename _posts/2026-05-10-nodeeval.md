# SCENARIO:

Evode Bank is a new generation online bank. This bank has created an online tool to attract new customers. Use this tool and find a way to read the file containing the flag!

# Reconnaissance

<img width="1918" height="787" alt="image" src="https://github.com/user-attachments/assets/b15babc4-007f-40d9-abc6-3a0b70f1ec9a" />


Upon navigating to the challenge URL it shows a Income/expense calculation page:

<img width="1878" height="814" alt="image" src="https://github.com/user-attachments/assets/42d66e56-c729-45be-9a08-467bb1ce4a0a" />


Pretty cool, what the app is during in essence is that is subtracting total expenses from income, using node `eval` function(The challenge tittle hinted this).

> It is well known that `eval` function in any programming language is a dangerous function that do leads to code execution.
> 

### Analyzing of request parameters in burp

<img width="1156" height="570" alt="image" src="https://github.com/user-attachments/assets/436f24be-4808-4551-8405-8a161420a0c7" />


Since the challenge hinted at `eval` function I then move forward to guess what the line of code is   responsible for the calculation would look like. Maybe not any of these exactly but something related :xD

```jsx
 eval(salary-(housing+phone+transport+insurance+credits+taxes+hobbies))
 or 
 eval(salary)-eval(housing)-eval(phone)-eval(transport)-eval(insurance)-eval(credits)-eval(taxes)-eval(hobbies)
```

### Check if any defense mechanism is in-place

Adding a string to the salary parameter in burp

<img width="1156" height="574" alt="image" src="https://github.com/user-attachments/assets/3875f92b-1405-405f-8a5a-dd9603a790cb" />


It gives a syntax error, the error is not custom, it’s just a generic error message which gives a hint that there might no be a defense in-place(not sure though)

<img width="1152" height="622" alt="image" src="https://github.com/user-attachments/assets/72df38f6-f93e-4412-8f18-e0d503cac8cf" />


Changing the salary value parameter to `7*7` , it gives a `-8151` which implies `7*7` which equals `49` is being executed i.e something like this `(eval(7*7))` might have occur. With this, it is clear that the salary parameter value is being passed to eval function separately(`eval(salary)`). 

# Exploitation

From my assumption in the recon phase (Salary parameter is  passed to an eval function). I then decided to use [@OrhanAlbay](https://x.com/OrhanAlbay) payload that uses `arguments[1]` as responsible object to get code execution

```jsx
arguments[1].end(require('child_process').execSync('whoami'))
```

I input this in the salary parameter value and `whoami` get execute on the server which confirm code execution
